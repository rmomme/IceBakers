IceBakers – installation

1. Opret en NY EmailJS template. To Email: info@icebakers.com (fast adresse). Subject: Ny IceBakers forespørgsel. Body: {{message}}. Reply To: {{email}}.
2. Template ID template_zv81urg er nu indsat i index.html. Public key og service ID er forudfyldt fra tidligere samtale, men skal verificeres i EmailJS.
3. Upload alle filer til en HTTPS-webserver. Test en forespørgsel og kontroller modtagelse.
4. Priser redigeres i products-listen i index.html. Alle priser inkl. moms. Fryserpriser er pr. forespørgsel; lejeperiode er ikke fastlagt.
